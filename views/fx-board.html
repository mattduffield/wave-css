wc-fx-board & wc-fx-console

A multi-zone FX board. The station (wc-fx-board) plays audio/video locally; the master (wc-fx-console) remote-controls zones by sending COMMANDs. Here there is no server — the two components are bridged in-page: the console's outgoing message events are fed to the board's .receive(), and the board's STATE message events are fed back to the console's .receive(). Try the console pads, then watch the station light up and the console's live indicator update.
