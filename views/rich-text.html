wc-rich-text

A form-associated rich-text / markdown editor. Submits its content as a normal named value (FACE), so the standard save path stores it like a wc-textarea. Pairs with wc-markdown-viewer for display.

Email compose (underline + device image upload)

        

          The image button opens a device file picker, uploads to
          image-upload-url, and inserts the returned hosted URL (email clients
          need hosted images, not data URIs). This demo mocks the upload to a local
          blob: URL so it works offline.
        

        
          
          
        
      


      

        
Images: resize, align, alt text

        

          Click an image (or put the caret next to it and press Shift+→) to select it: drag a corner
          (mouse, touch or pen) to resize with the aspect kept, or use the image toolbar — S / M / L / Original,
          Width in pixels, Left / Center / Right, Alt text, Remove. Enter/Space
          opens the toolbar, Esc closes it, Delete removes the image. Everything is saved as
          attributes and inline styles, so it survives email programs. Try: logo → M + Center; QR code → S.

Variables (fields)

        

          With fields, each {name} shows as a box with its label (red when it isn't a
          field). Click Insert field or type { to pick one; Esc after {
          types a plain brace. The value keeps the plain {name} text for the server to fill.
        

        
          
          
        
      


    


    
      // Offline mock for the image upload endpoint: return a blob: URL from the picked file,
      // standing in for the server's hosted URL. Scoped to the demo endpoint; all other
      // requests pass through. Lives in  so it runs after an htmx swap too.
      (function () {
        if (window.__rtUploadPatched) return;
        window.__rtUploadPatched = true;
        const orig = window.fetch.bind(window);
        window.fetch = async (url, opts) => {
          if (typeof url === 'string' && url.indexOf('/demo/upload-image') !== -1) {
            const file = opts && opts.body && opts.body.get ? opts.body.get('image') : null;
            const objectUrl = file ? URL.createObjectURL(file) : '';
            return { ok: true, json: async () => ({ url: objectUrl }) };
          }
          return orig(url, opts);
        };
      })();
