overlay AS AN HTMX INDICATOR (no wrapper) — idle is click-through

The button below sits BEHIND an idle <wc-loader class="htmx-indicator" overlay>. While idle the overlay is invisible + click-through, so the button is clickable. Toggle .htmx-request (or fire an EventHub show) to reveal the dimmed backdrop + spinner and block clicks.
