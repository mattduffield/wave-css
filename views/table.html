wc-table

A lightweight data-driven table component. Define columns with <wc-table-col>, load data from a URL or static JSON. Uses the existing wc-table CSS classes internally.

Static Data with Column Definitions

Data provided via items attribute. Columns defined with <wc-table-col>. Click headers to sort.

<wc-table striped hoverable clickable items='[...]'>
  <wc-table-col field="first_name" label="First Name" sortable></wc-table-col>
  <wc-table-col field="deal_value" label="Deal Value" align="right" format="currency" sortable></wc-table-col>
</wc-table>

Compact Table (size="sm")

Dense data view with smaller padding. Good for dashboards and data exploration.

Auto-Columns from display-member

No <wc-table-col> needed. Just list field names in the display-member attribute.

<wc-table striped hoverable
          display-member="name,email,phone,city"
          items='[...]'>
</wc-table>

Empty State

Custom message when no data is available.

Date and Number Formatting

Use format attribute on columns: date, datetime, currency, number, boolean.

Row Click Events

Click a row to see the event data. Double-click for a different event.

Click a row...

Programmatic Data Update

Set data via JavaScript using the .data property or .refresh() method.

Pagination + Search + Row numbers (data mode)

paginate page-size="8" searchable row-numbers — client-side pager (« Prev · numbered · Next » · go-to-page · X–Y of N), a debounced search box, and a global # column. The Email column is filterable (search scopes to it). Fires wc-table:page / wc-table:filter.

Enhance mode — authored composite rows (zero data binding)

A <wc-table> wrapping an authored <table> (no url/items) is auto-enhanced in place: composite cells (avatar + name + DOB, badges) are preserved exactly, while paging / search / sort / row-numbers are added. Search matches data-search; sort uses data-sort / data-type.

External filter bar — search-input + filter-attr

The search box lives in an app-owned filter row (next to a "Master Event" <select>), bound via search-input="#p-search". The select filters client-side by tr[data-event] via filter-attr + filter-input — zero round-trips, and the <wc-table> renders no internal search box.
