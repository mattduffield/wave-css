wc-record-lookup — search an existing collection, then emit or fill

Typeahead that searches a server endpoint (source of truth) and, on select, emits the record or fills sibling fields. These demos use an in-page mock (el.searchHandler) instead of a real endpoint. Type av / no / ri to see matches.

mode="select"

Emits record:selected with the full record; clears the box.

mode="hint"

Non-blocking banner: "Looks like … — use existing?" with an action button.

mode="fill" — "use this family"

Fills the fields below from the chosen household record.
