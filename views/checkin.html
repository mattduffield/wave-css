wc-checkin — scan-to-check-in / check-out station

The component captures a scanned code (USB keyboard-wedge and/or camera), POSTs it to the server, and renders the server's allow/deny verdict — the server is authoritative. These demos use an in-page mock (el.requestHandler) instead of a real endpoint. Use the Simulate scan boxes to test without a physical scanner.

Check-IN (usb + camera)

Scan starting with OK → ALLOWED, anything else → DENIED.

Check-OUT (two-step, with override)

First scan a child (CH-*) → shows authorized pickups + "scan pickup". Then scan a pickup: PU-OK releases; anything else denies (with Override).
