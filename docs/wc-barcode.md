# WC-Barcode Web Component

Renders a scannable code (QR by default, Code128 optional) plus the human-readable value, as crisp print-quality SVG. Self-contained — the QR and Code128 generators are bundled, so it works offline with no external CDN. Display-only (no form participation, no events).

## Features

- QR (default) and Code128 symbologies, both generated by bundled encoders (no CDN)
- Crisp, print-quality SVG output
- Configurable human-readable value placement (right, bottom, or none)
- QR error-correction levels (L/M/Q/H)
- Optional caption above the code (e.g. an attendee name)
- Always pure black-on-white so scanners read it reliably (never theme-tinted)
- `@media print` forces black-on-white and removes shadows/margins for clean labels
- Accessible: `role="img"` + `aria-label="barcode <value>"`

## Basic Usage

```html
<wc-barcode value="IE-4F9K2" caption="Ava Noble"></wc-barcode>
<wc-barcode value="IE-4F9K2" symbology="code128" label="bottom" size="64"></wc-barcode>
```

## Attributes

| Attribute | Default | Description |
|-----------|---------|-------------|
| `value` | — | The code to encode (required; empty renders nothing) |
| `symbology` | `qr` | `qr` or `code128` |
| `label` | `right` | Where to show the human-readable value: `right`, `bottom`, or `none` |
| `size` | `96` (QR) / `64` (Code128) | QR square px, or Code128 bar-height px |
| `ec-level` | `M` | QR error correction: `L`, `M`, `Q`, or `H` |
| `caption` | — | Optional small text shown above the code |
| `class` | — | CSS classes |

## Methods

| Method | Description |
|--------|-------------|
| `value` (get/set property) | Reads or sets the encoded value; setting re-renders |

## Examples

```html
<!-- QR with high error correction and a caption -->
<wc-barcode value="ORDER-88231" ec-level="H" caption="Order #88231"></wc-barcode>

<!-- Code128 wristband label, value beneath -->
<wc-barcode value="A1B2C3" symbology="code128" label="bottom" size="72"></wc-barcode>

<!-- Set the value programmatically -->
<wc-barcode id="bc"></wc-barcode>
<script>
  document.getElementById('bc').value = 'IE-4F9K2';
</script>
```

## Notes

- Extends `WcBaseComponent`.
- The QR generator is a compact port of Project Nayuki's encoder (byte mode, versions 1–40); Code128 uses Code Set B. Both are bundled in the component — no external requests, works offline.
- The code region is always pure black modules/bars on a white background so scanners read it reliably; only the caption/label text uses the theme text color (`--text-1`).
- Display-only: no form value, no custom events.
